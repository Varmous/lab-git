# Техническое задание на разработку программы
## Вычисление чисел Фибоначчи и 20-угольных фигурных чисел

### 1. Общие сведения
- Наименование: программа вычисления чисел Фибоначчи и 20-угольных чисел.
- Исполнитель: студент гр. 5.506-2 Богатырёв Д. М.
- Основание: задание на лабораторную работу.
- Сроки: 2026 учебный год.

### 2. Назначение и цели создания
Программа предназначена для вычисления n-го числа Фибоначчи и n-го 20-угольного фигурного числа. Цель - освоить модульную разработку на Python 3 и основы Git.

### 3. Характеристика объекта автоматизации
Объект - процесс вычисления математических последовательностей. Программа работает в командной строке без графического интерфейса.

### 4. Требования к системе

#### 4.1 Требования к системе в целом
- Язык реализации: Python 3.8+.
- Запуск: командная строка.
- Кроссплатформенность: Windows / Linux / macOS.

#### 4.2 Требования к функциям
- Функция 1. Вычисление n-го числа Фибоначчи при вызове python main.py fib.
- Функция 2. Вычисление n-го 20-угольного числа при вызове python main.py fig.
- Функция 3. Запрос числа n у пользователя через input().
- Функция 4. Проверка корректности ввода (только целые числа).
- Функция 5. Проверка диапазона (n >= 0 для F, n >= 1 для P).
- Функция 6. Вывод сообщения об ошибке при неверном вводе.
- Функция 7. Вывод справки при запуске без аргументов.

#### 4.3 Требования к видам обеспечения

Программное обеспечение:
- Модуль fibonacci.py - вычисление чисел Фибоначчи.
- Модуль figurate.py - вычисление 20-угольных чисел.
- Модуль main.py - CLI и точка входа.

Информационное обеспечение:
- Ввод: команда (fib / fig) и целое число n.
- Вывод: результат в формате F(n) = ... или P20(n) = ...

Лингвистическое обеспечение:
- Язык интерфейса: русский.

### 5. Требования к вводу
- Команда: fib или fig.
- Для Фибоначчи: n >= 0.
- Для 20-угольного числа: n >= 1.
- При неверном вводе программа выводит сообщение и повторяет запрос.
