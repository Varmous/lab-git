# Software Requirements Specification (SRS)
## Программа: fibo-figurate-cli

### 1. Введение
- 1.1 Назначение. Программа вычисляет числа Фибоначчи и 20-угольные числа через CLI.
- 1.2 Область применения. Программный продукт fibo-figurate-cli, версия 1.0.
- 1.3 Определения. F(n) - число Фибоначчи, P(n) - 20-угольное число.
- 1.4 Ссылки. ISO/IEC/IEEE 29148-2011.
- 1.5 Обзор. Документ состоит из трёх разделов. Раздел 1 - введение. Раздел 2 - общее описание продукта. Раздел 3 - конкретные требования с идентификаторами.

### 2. Общее описание

2.1 Перспектива продукта. Самостоятельное CLI-приложение.

2.2 Функции продукта.
1. Приём команды (fib / fig) из аргументов командной строки.
2. Запрос числа n через input().
3. Проверка входных данных.
4. Вычисление результата.
5. Вывод результата.

2.3 Характеристики пользователя. Студент, преподаватель.

2.4 Ограничения. Python 3.8+, без сторонних зависимостей.

2.5 Допущения. Пользователь вводит корректные данные.

### 3. Конкретные требования

3.1 Функциональные требования

| ID   | Описание                    | Вход           | Выход              |
|------|-----------------------------|----------------|--------------------|
| FR-1 | Вычислить число Фибоначчи   | Целое n>=0     | F(n) = <int>       |
| FR-2 | Вычислить 20-угольное число | Целое n>=1     | P20(n) = <int>     |
| FR-3 | Проверить тип ввода         | Строка         | Ошибка, если не int|
| FR-4 | Проверить диапазон          | int            | Ошибка             |
| FR-5 | Показать справку            | Без аргументов | Текст справки      |

3.2 Требования к внешнему интерфейсу
- CLI: python main.py fib / fig.
- Коды возврата: 0 - успех.

3.3 Требования к производительности
- Время вычисления F(1000) < 1 сек.
- Память < 10 МБ.

3.4 Ограничения проектирования
- ООП и модульность.
- Docstrings у всех публичных функций.

3.5 Атрибуты программной системы
- Сопровождаемость: модульная архитектура.
- Переносимость: Linux / Windows / macOS.
