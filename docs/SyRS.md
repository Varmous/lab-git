# System Requirements Specification (SyRS)
## Система: CLI-вычислитель Фибоначчи и 20-угольных чисел

### 1. Введение
- 1.1 Назначение. Документ определяет системные требования к программе вычисления последовательностей.
- 1.2 Область применения. Программа охватывает вычисление чисел Фибоначчи и 20-угольных чисел.
- 1.3 Определения. CLI - командный интерфейс, n - порядковый номер.
- 1.4 Ссылки. ISO/IEC/IEEE 29148-2011, ГОСТ 34.602-2020.
- 1.5 Обзор. Документ состоит из трёх разделов. Раздел 1 - введение. Раздел 2 - общее описание системы. Раздел 3 - конкретные требования с идентификаторами.

### 2. Общее описание

2.1 Перспектива продукта. Программа автономна, работает в командной строке. Пользователь вызывает команду fib или fig, затем вводит число n.

2.2 Функции продукта.
- Вычисление числа Фибоначчи.
- Вычисление 20-угольного числа.
- Валидация ввода.
- Вывод справки.

2.3 Характеристики пользователя. Пользователь знаком с базовыми действиями в командной строке.

2.4 Ограничения. Только целые числа. Только указанные последовательности. Только текстовый интерфейс.

2.5 Допущения. Python 3.8+ установлен в системе.

### 3. Конкретные требования

3.1 Функциональные требования

| ID  | Требование                                 | Приоритет |
|-----|--------------------------------------------|-----------|
| F-1 | Вычисление F(n) для n >= 0                 | Высокий   |
| F-2 | Вычисление P(n) = (18n^2-16n)/2 для n >= 1 | Высокий   |
| F-3 | Проверка типа входного значения (целое)    | Высокий   |
| F-4 | Проверка диапазона значения n              | Высокий   |
| F-5 | Вывод сообщения об ошибке                  | Средний   |
| F-6 | Вывод справки при запуске без аргументов   | Средний   |

3.2 Требования к интерфейсу

Запуск: py main.py fib (или fig). Далее программа запрашивает n. Ввод проверяется, при ошибке повторяется запрос.

3.3 Производительность. Вычисление F(1000) - менее 1 секунды.

3.4 Ограничения.
- Python 3.8+.
- Без внешних библиотек.

3.5 Атрибуты системы.
- Надёжность: валидация всех входных данных.
- Удобство: понятные сообщения об ошибках.
- Переносимость: кроссплатформенность.
