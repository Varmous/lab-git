# Лабораторная работа 1

## Тема
Вычисление чисел Фибоначчи и 20-угольных фигурных чисел.

## Задача
Разработать программу на Python 3 с командным интерфейсом, которая позволяет вычислять:
- n-е число Фибоначчи F(n), n >= 0
- n-е 20-угольное фигурное число P(n), n >= 1

## Режим работы и валидация
Программа вызывается из командной строки:
    py main.py fib   - вычисление числа Фибоначчи
    py main.py fig   - вычисление 20-угольного числа
    py main.py       - справка

После вызова команды программа запрашивает число n. 
Валидация ввода включает следующие проверки:
- Ввод должен быть целым числом.
- Для Фибоначчи: n >= 0.
- Для 20-угольного числа: n >= 1.
- Максимальное значение n: 5000 (для предотвращения зависаний).
- Пустой ввод отклоняется с сообщением об ошибке.
- Ввод длиной более 10 символов отклоняется.
- Поддерживается корректный выход по Ctrl+C и Ctrl+Z.
