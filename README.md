# Лабораторная работа: Git + Python CLI

## Тема
Вычисление чисел Фибоначчи и 20-угольных фигурных чисел.

## Задача
Разработать программу на Python 3 с командным интерфейсом, которая позволяет вычислять:
- n-е число Фибоначчи F(n), n >= 0
- n-е 20-угольное фигурное число P(n), n >= 1

## Формулы
- Фибоначчи: F(0)=0, F(1)=1, F(n) = F(n-1) + F(n-2)
- 20-угольное число: P(n) = (18n^2 - 16n) / 2

## Запуск
    python main.py fib   - вычисление числа Фибоначчи
    python main.py fig   - вычисление 20-угольного числа
    python main.py       - справка

После вызова команды программа запрашивает число n. Ввод проверяется: принимаются только целые числа в допустимом диапазоне. При ошибке программа сообщает о ней и повторяет запрос.

## Требования
- Python 3.8+
- Без внешних библиотек
